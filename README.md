# Capstone Project – Sales Analytics Solution

## Project Overview

This project demonstrates a complete end-to-end Sales Analytics solution using Python, NumPy, Pandas, SQL Server, Excel, and Power BI.

The workflow covers data loading, cleaning, exploratory data analysis, SQL analysis, dashboard development, and business insights generation.
